# Game-of-Life

### This Python program is a simulation of Conway’s Game of Life, a cellular automaton that models how cells evolve over time based on simple rules. Using the Pygame library, it creates a grid-based world where each cell is either alive (black) or dead (white). The simulation begins with a randomized grid and updates continuously through generations. Each cell's next state is determined by the number of alive neighbors it has: a live cell survives if it has 2 or 3 neighbors, and a dead cell becomes alive if it has exactly 3. These rules simulate birth, survival, and death across the board. The screen also includes a side panel displaying stats such as the number of rows and columns, the current generation number, and the percentage of cells that are alive. The program visually updates the grid in each generation and continues running until the user closes the window.
