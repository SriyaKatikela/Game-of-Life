# Game-of-Life

### This Python program simulates Conway's Game of Life, a classic cellular automaton devised by mathematician John Conway. The simulation takes place on a 2D grid where each cell is either alive or dead. The grid evolves over time according to a set of simple rules: a living cell with two or three living neighbors survives, a dead cell with exactly three living neighbors becomes alive, and all other cells die or remain dead. The program initializes the grid with a starting pattern (either random or predefined), and with each update cycle, it computes the next generation of cells based on the rules. Visually, the simulation displays the grid, typically using a graphical interface where alive cells are shown in one color (like black) and dead cells in another (like white). The simulation runs continuously, updating the grid to show how complex and often unpredictable patterns can emerge from the initial configuration, demonstrating the power of simple rules to create dynamic, evolving systems.
